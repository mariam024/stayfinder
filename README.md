📌 Project Overview

Project Name

StayFinder

Description

StayFinder is a modern hotel discovery web application that helps users search, explore, and save hotels from around the world. The application provides a clean user experience with responsive design, real-time data from external APIs, filtering, sorting, and favorites management.

🎯 Goals
Practice React professionally.
Work with real APIs.
Learn state management.
Improve folder structure.
Build a portfolio-ready project.
